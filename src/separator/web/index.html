Separator

Removes dialogue from production sound and writes the remaining sounds as UCS-named FX files with regions.
  • Source / Destination: the chips at the top left. Or drag audio files and folders into the window; more drops add to the list. Originals are never changed.
  • Track Filter: per project. Scan lists every track name, a click switches Use/Drop.
  • Listen: ▶ or Space plays the selected take, a click into the waveform jumps there. Original plays the take as recorded, Result only the parts Separator keeps. Choose the audio output under Options (System default follows your Mac's sound settings).
  • Analyze preview: shows what gets cut and what stays for the selected take, without writing anything. Double-click a take does the same.
  • Length: shorter results are dropped, longer ones are split at sound boundaries (0 = unlimited). Gap: silence between sounds in a sausage file.
  • Options: Creator ID, test run, sausage files, wild tracks, project sausages, UCS folders, single tracks, light/dark.
  • FX Library / DX Delete: FX Library writes UCS-named sound effect files. DX Delete keeps every file where it is, with its name and all tracks, and only cuts the dialogue and slates; markers show what is left. Both keep the original metadata.
  • Selected takes only: tick takes in the list (or Cmd-click, Shift-click for a range). Start then converts only those, also takes that were done before.
  • Min. level (Options): parts quieter than this are cut and never written.
  • Stop: after the current take. The next start picks up where it left off.
File names: CatID_FXName_CreatorID_Project_Sc-Tk.wav. Description, keywords (English and German) and UCS fields go into bext, iXML and INFO.
